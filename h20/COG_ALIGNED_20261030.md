# Cog 管线对齐后的第一批可信数字（2026-10-30）

## 问题背景

此前我们自研的 Cog 管线与官方 `CogVideoXPipeline` 在同 prompt/seed/步数下 LPIPS = **0.674**，
导致 Cog 的所有数字**不能与 RA 同表**。今天改变了做法：

> **不再修自研管线，而是直接在官方 pipeline 上 monkey-patch 缓存**
> （`repro/results/20261030_cog_aligned/cog_sweep.py`）。
> 这样调度、条件嵌入、VAE、guidance 全部与官方一致，对齐问题从构造上消失。

## 结果（官方管线，17 帧，30 步，N=19 → 2.58×，8 prompt）

| 臂 | LPIPS mean | median |
|---|---:|---:|
| **reuse（α=0）** | **0.1483** | 0.1367 |
| 阻尼外推 α=0.25 | 0.1518 | 0.1429 |
| 阻尼外推 α=0.5 | 0.1595 | 0.1551 |
| 外推 α=1.0 | 0.1835 | 0.1758 |

**单调：任何外推都比纯复用差。**

## 三个结论

1. **Cog 上的第一版可信基线是 reuse = 0.1483**（同源、可核查）；
2. **外推基座是负收益**——这与 Wan 上的观察一致（ex1 0.208 vs tea_gap 0.191，而 reuse 可能更好）；
3. **我们的方法在 Cog 上还没有跑过这个对齐 harness**（当前只有 Wan 上有 tea_gap/fr），
   下一次必须在这个 harness 里实现“模型修正”，否则 Cog 行仍然是空的。

## 待办（最高优先）

- **Wan 上补 `reuse` 这一臂**（昨天表里没有！）。如果 50 个 prompt 上 reuse < 我们的 0.1909，
  说明我们的方法被最简单的基线支配，这是必须立刻知道的；
- 在 Cog 对齐 harness 里实现模型修正（把 64 维 token 空间的在线对角模型搬过来）；
- 用对齐 harness 重跑 RA 的 Cog 数字做同口径对比。
