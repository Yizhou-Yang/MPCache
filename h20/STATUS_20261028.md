## 3. 为什么落后（源码级结论，见 PITFALLS P23）

RA 跳过时：`hidden = embed(当前 latent) + 上一步残差`，残差是逐 token 高维张量，基座跟着当前输入走。
我们：冻结的输出外推 + 64 参数全局对角修正。差一档。

| 变体 | 原理 | LPIPS p0 / p1 |

**结论**：在“不碰网络内部”的前提下，`tea_gap` 已经是最优的；两条独立重建路线（状态外推、求解器反解）都失败，原因是求解器的多步记账不可绕过。

## 8. 与 RA 的差距归因（最终）

| 差距来源 | 证据 |
|---|---|
| 重建空间不同 | RA 在**隐藏层**携带逐 token 残差；我们在**输出层**用 64 参数全局模型 |
| 基座精度 | RA 每步用当前 latent 重新嵌入；我们的基座是外推值 |
| 调度 | 不是主因：TeaCache 用同类调度只得 0.168，与我们持平 |

要在 Wan 上超过 RA，必须获得**逐 token、跟随当前输入**的重建能力——在当前“只替换网络输出”的框架内不可达。
